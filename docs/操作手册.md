# 沙漠掘金 · 现场操作手册

面向主持人/讲师。目标：一场 8 队、25 天的沙盘，从开机到颁奖不超过 3 小时，中途不出事故。

---

## 0. 开营前 30 分钟检查

1. 服务器起来了：浏览器打开 `http://<地址>:8080/healthz` 应返回 `{"ok":true}`。
2. 管理员登录 `/admin`，默认 `A / Aa0123456789`（**第一次上台前先在「账号安全」改密**）。
3. 「指挥台」四项统计：队伍 8、已提交 0、出局 0；状态应为 `草稿`。等玩家陆续登录，「在线」会从 0 往上加。
4. 「地图编辑器」点「校验」，`ok=true`；点「平衡测算」，记下 `往返天数 / 可挖天数 / 净收益`，心里有数。
5. 「天气矩阵」确认第 1 天和第 25 天没有把藏宝山设成沙尘暴（会死人，除非你就想这么狠）。
6. 投屏机开 `/screen`（F11 全屏，1920×1080 最佳），确认地图铺满、倒计时可见。
7. 每队一台设备（手机/平板/笔电都行），提前用 `teamNN / desert888` 登录一次，看到候场页即可。
8. 网络：所有设备与服务器在同一 Wi-Fi；公网部署就不用了。

> 玩家端断线不影响计时；页面 6 秒轮询兜底，重新打开会自动回到当前局面。

---

## 1. 开局（10 分钟准备 + 简报）

1. 后台「指挥台」点 **开营** → 进入 `准备` 阶段（默认 600 秒），玩家端出现任务简报、规则、在场队伍。
2. 这段时间讲师讲规则：地图、天气、消耗、采购、载重、金价与税。
3. 点 **跳下一阶段** 跳过准备 → `简报`（15 秒）→ 自动进入 **第 1 天行动**（默认 300 秒）。
4. 第 1 天很关键：队伍只有 1000 元现金、0 水 0 食物，**必须先在商店采购再出发**；留在大本营不扣粮也不判死。

## 2. 逐日节奏（每天约 2 分钟）

```
行动（120s） → 结算（瞬时） → 日报（30s） → 次日行动
```

- 队伍在「今日行程」选一个相邻格或原地停留；采购、换粮、买情报、装备都在这一天一起提交。
- 地图上点相邻格也能直接选目标；提交后按钮变「撤回」，结算前都能改。
- 全员提交会自动提前结算（不想提前就在参数里关 `全员提交自动结算`）。
- 到点没提交按「原地停留」结算，**不会卡局**。
- 结算后每人弹出日报：行程、消耗、采购、账目、结余、建议。讲师可在大屏同步看排名变化。

主持建议：报时用「还剩 60 秒 / 30 秒」，最后 30 秒玩家端倒计时会变红心跳，大屏也会闪。

## 3. 控场按钮怎么用

| 按钮 | 什么时候用 |
|---|---|
| 跳下一阶段 | 准备讲完了想立刻开始；日报看完了想快进 |
| +2 / +5 分钟 | 队伍集体喊不够时间；只延长当前阶段 |
| 暂停计时 / 恢复计时 | 临时答疑、放视频、有人上厕所 |
| 立即结算当天 | 想让所有人同时停手（比如统一讲评） |
| 结束本局 | 提前收尾，按当前资产 + 已归营金价出终局榜 |
| 重新开营 | 重开一局（保留当前配置） |
| 重置本局（保留队伍） | 清空进度、物资回到初始，队伍和账号不动 —— 彩排最常用 |

## 4. 突发处理

- **某队掉线**：不用管，计时照走；重开页面自动续上。指挥台「在线」列会变灰。
- **误判死亡**：队伍表里点该队「复活」——保留原地位置，水粮补到至少各 1，继续走；想让它直接回基地就用「重置」。
- **有人手滑买了 50 顶帐篷**：结算前让他在玩家端撤回；已结算就在队伍表「重置」该队重来一天。
- **想临时加难度**：天气矩阵把某几天藏宝山改成「沙暴+高温」，或参数中心把水价调到 40；保存即生效，玩家端会收到提示。
- **想换地图**：地图编辑器改节点/邻接，先点「校验」再「保存地图」；保存后所有玩家看到新图，**已在半路的位置不会自动迁移**，建议在两局之间换图。
- **时间不够**：+5 分钟最稳；不要连点「跳下一阶段」，会直接跳到次日。

## 5. 收尾（10 分钟）

1. 最后一队归营或第 25 天结算后，点 **结束本局**。
2. 玩家端弹出终局榜：净收益、金价、税额、免税标记；大屏切「归营·金价榜」。
3. 后台「报表导出」下三份 xlsx：
   - `daily`：逐日日报（哪天谁在哪、消耗多少、账目变动）
   - `cost`：成本明细（采购、消耗、税）
   - `final`：终局计分（净收益排名，可直接投屏/发群）
4. 「审计日志」留档：谁改过参数、谁被判死/复活，都有前后值。
5. 讲评：拿 `final` 表讲三件事——谁赌对了天气、谁载重算错、谁归营太晚被税吃掉利润。

## 6. 下一场

- 保留配置重开：指挥台「重置本局（保留队伍）」→「重新开营」。
- 换一套规则：参数中心点预设 `PPT` / `TABLE` / `CLASSIC`，再微调。
- 换一批队伍：队伍与账号里删旧队、CSV 批量导入新队（`名称,口号,颜色`），再「批量重置密码」。
- 备份：`bash scripts/backup.sh`；换服务器时把 `data/` 整个目录带走（含 `.jwt-secret`）。

## 附：默认节奏与数值

| 项 | 默认 |
|---|---|
| 总天数 | 25 |
| 准备 / 简报 / 第 1 天 / 常规日 / 日报 | 600s / 15s / 300s / 120s / 30s |
| 起始 | 现金 1000、载重 1000 磅、水 0、食物 0 |
| 价格 | 水 25/皮囊(50磅)、食物 10/盘(20磅)、帐篷 400(3 次)、指南针 100 |
| 金价 | 归营名次 1000 / 900 / 850 …，按块计价，税 20%，挖金最多免税 |
| 平衡测算 | 单程 9 天、往返 18 天、可挖 6 天，理论净收益约 5000+ |
